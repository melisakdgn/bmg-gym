# BMG Gym Tracker

Black-and-white gym tracker for Berke and Melis. Installable on iPhone, works offline.

**App:** https://melisakdgn.github.io/bmg-gym/

On iPhone: open the link in Safari → Share → Add to Home Screen → open it once while online.

All data (workouts, exercises, time logs) is stored on the device only. Use the profile button → Export backup to save a copy.
